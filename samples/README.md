# Sample scripts

Official examples, the same ones built into the Script panel's **Sample scripts** menu.

| File | What it does | Shows |
|---|---|---|
| [infection.js](infection.js) | Percentage of blocks taken by Corruption, Crimson and Hallow | `histogram`, `TileGroups`, `stat`, `map.highlight` |
| [infection-report.js](infection-report.js) | Asks for a biome, opens a report | `prompt`, `modal`, `section`, `table`, `chart` |
| [life-crystals.js](life-crystals.js) | Marks every Life Crystal, lists the closest to spawn | `forEach`, frame check, `map.markAll` |
| [chest-items.js](chest-items.js) | Finds chests that contain an item | `prompt` item field, `tw.chests`, `map.markAll` |
| [ores.js](ores.js) | Ore counts per layer | `regions`, `histogram` with a region |
| [ores-in-region.js](ores-in-region.js) | Ore counts in an area you drag on the map (API 1.1) | `pickRegion`, `chart`, `highlight` with a region |
| [ebonstone-to-stone.js](ebonstone-to-stone.js) | Turns every Ebonstone block into Stone after you approve the preview (API 1.2, **edits the world**) | `tw.edit.replace`, `commit` |
| [purify-region.js](purify-region.js) | Purifies Corruption / Crimson blocks in an area you pick (API 1.2, **edits the world**) | `pickRegion`, `replace` with a function, `commit` |

## Open in TerraWorld

Each link opens TerraWorld with the script **loaded in the editor, not run**. Load a world (or it waits until you do),
read the script, then press **Run**. Scripts that edit the world still show a preview and wait for **Apply**.
