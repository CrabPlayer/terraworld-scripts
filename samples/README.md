# Sample scripts

Official examples, the same ones built into the Script panel's **Sample scripts** menu.

| File | What it does | Shows |
|---|---|---|
| [infection.js](infection.js) | Percentage of blocks taken by Corruption, Crimson and Hallow | `histogram`, `TileGroups`, `stat`, `map.highlight` |
| [infection-report.js](infection-report.js) | Asks for a biome, opens a report | `prompt`, `modal`, `section`, `table`, `chart` |
| [life-crystals.js](life-crystals.js) | Marks every Life Crystal, lists the closest to spawn | `forEach`, frame check, `map.markAll` |
| [chest-items.js](chest-items.js) | Finds chests that contain an item | `prompt` item field, `tw.chests`, `map.markAll` |
| [ores.js](ores.js) | Ore counts per layer | `regions`, `histogram` with a region |
