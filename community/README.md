# Community scripts

Scripts shared by TerraWorld users. Each author has a folder named after their GitHub username:

```
community/
  your-github-name/
    my-script.js
```

Keep it flat: put scripts directly in your folder, no sub-folders. TerraWorld reads at most three folder levels
inside `twscript`, and `terraworld-scripts/community/<author>/` already uses all three.

Read a script before running it. Scripts here are reviewed, but they are written by other users.
See [CONTRIBUTING.md](../CONTRIBUTING.md) to add yours.
